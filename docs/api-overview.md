# Обзор API mindmap

Главный сценарий приложения:

1. Пользователь входит по почте или через Google OAuth 2.0.
2. Заполняет обязательный профиль через `GET/PUT /api/profile`.
3. Выбирает Gemini или DeepSeek и сохраняет проверенный ключ через `PUT /api/ai-settings`.
4. Отправляет свободное описание цели в `POST /api/requests/analyze`.
5. Отвечает на 3–15 последовательных вопросов через `POST /api/requests/{id}/answers`.
6. Получает оценку через `POST /api/requests/{id}/evaluate`.
7. Для реалистичной цели создаёт план через `POST /api/requests/{id}/generate-plan`.

План всегда имеет два уровня: этапы и конечные шаги. Конечный шаг имеет дедлайн и один из двух рабочих статусов: `TODO` или `DONE`. Зависимый шаг можно читать и редактировать, но нельзя завершить раньше его зависимостей.

Пользовательский интерфейс не использует аналитику, версии генераций и техническую документацию. Полная актуальная схема находится в `openapi.yaml`.
